# A4 Physical Phone Acceptance

Open the live build:

https://alexandresalazar89-blip.github.io/GameZone/

The hub must show **3 games**, including **Runtime PCK Stub**.

## Required phone flow

1. Load the page from a clean/reloaded browser tab.
2. Confirm all three game cards appear.
3. Tap **Runtime PCK Stub**.
4. Confirm the game opens and is visibly labelled as the runtime PCK stub.
5. Move using the touch D-pad.
6. Press A once.
7. Press touch BACK and confirm the hub returns.
8. Launch **Runtime PCK Stub** again and confirm it still runs.
9. Return to the hub.
10. Launch each of the other two stubs and return with touch BACK.
11. Repeat one of the in-tree stubs once more.
12. Rotate portrait/landscape if convenient and confirm the hub remains usable.

## PASS criteria

- all 3 cards visible;
- runtime PCK game launches on the physical phone;
- touch movement works;
- touch BACK returns to hub;
- packed game relaunch works;
- both in-tree games still launch and return;
- no stale audio/input/state behavior is observed;
- hub remains usable.
